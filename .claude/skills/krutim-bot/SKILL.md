# Бот Крутим Тут — как дорабатывать быстро и безопасно

Это Telegram-бот отдела запуска и сопровождения франшизы шаурмы «Крутим Тут».
Партнёр уже купил франшизу — бот помогает ему открыть точку и вести её.
Бот НЕ продаёт и НЕ спрашивает про бюджет.

## Архитектура (важно понять перед правками)

- **`server.py`** — единственный источник логики (ответы, чек-листы, карточки, напоминания, отчёт).
  Это Flask-приложение, принимает апдейты Telegram через webhook.
- **`bot.py`** — тонкая обёртка-поллер: импортирует `server` и зовёт `server.process_update`.
  Логику в bot.py НЕ дублируем — правим только server.py, иначе версии разъедутся.
- **`supervisor.py`** — поднимает Flask + cloudflared-туннель, следит за ними, сам ставит webhook;
  при сбое DNS пересоздаёт туннель с новым адресом.
- **launchd-агент `com.krutim.bot`** (`~/Library/LaunchAgents/com.krutim.bot.plist`) — запускает
  супервизор при входе в систему и перезапускает, если он упал.
- **`bin/cloudflared`** — бинарь туннеля (даёт публичный адрес для webhook).
- **`manage.sh`** — управление одной командой (см. ниже).
- **`assets/designs/`** — рендеры точек и планы, которые бот шлёт партнёру.
- **`partners.json`** — рабочие данные партнёров (в .gitignore, НЕ коммитить).

Поток: Telegram → cloudflared-туннель → Flask (`server.py`) → `process_update` → ответ.

## Стиль ответов бота (соблюдать строго)

Бот говорит как живой сотрудник отдела запуска. Почему это важно: партнёр должен
чувствовать, что общается с человеком из компании, а не с роботом-методичкой.

- Только по-русски, простым языком, как в живой переписке.
- НЕТ звёздочкам, эмодзи, решёткам, markdown, нумерованным спискам, заголовкам.
- НЕТ приветствиям в каждом сообщении (поздоровались один раз — дальше по делу).
- Перечисляй через запятую внутри предложения, а не списком.
- Коротко: 3-4 предложения максимум.
- В конце — встречный вопрос по делу или следующий шаг, чтобы вести диалог.
- Функция `clean()` в server.py подчищает случайные звёздочки/эмодзи/приветствия
  на выходе — это страховка, но писать сразу чисто всё равно нужно.

Плохо: «**Критерии выбора:** 1. Проходимость 2. Видимость 😊»
Хорошо: «По аренде главное проходимость, минимум 500 человек в час в пик. Дальше
видимость, чтобы точку было видно с улицы. В каком городе смотришь помещение?»

## Как добавить новую тему-ответ

Это самая частая задача. Темы живут в функции `instant_answer(t)` в `server.py`:
бот ищет ключевые слова в сообщении и возвращает готовый текст. AI (`ask_ai`) —
только запасной вариант для нестандартных вопросов.

Добавь новую ветку перед `return None`:

```python
if any(w in t for w in ["ключевое", "слово", "синоним"]):
    return ("Короткий человеческий ответ по делу, без звёздочек и смайликов, "
            "максимум 3-4 предложения. Встречный вопрос в конце?")
```

Правила:
- Ключевые слова — в нижнем регистре, бери корни слов («зарплат» поймает
  «зарплата/зарплате/зарплаты»). Подумай о синонимах и опечатках.
- Порядок веток важен: первая сработавшая выигрывает. Если новое слово пересекается
  со старой веткой, поставь новую ветку выше или сделай ключи точнее. Проверь, что
  слово не перехватывается веткой выше (так было с «отделк», которую ловил «ремонт»).
- Опирайся на реальные данные франшизы (см. раздел «Факты» ниже), не выдумывай цифры.

## Как добавить чек-лист (с тапающимися галочками)

Чек-листы — это inline-кнопки, которые партнёр отмечает. Они пишутся в карточку
партнёра и ведут к следующему этапу.

1. Добавь запись в `CHECKLISTS` (ключ, `title`, `items`, `done`).
2. В `route()` добавь ключевые слова → `send_checklist(chat_id, "ключ")`.
3. В `NEXT_STEP` добавь, что бот предложит после закрытия чек-листа (ведение по этапам:
   локация → дизайн → оборудование → открытие).

## Как добавить фото (дизайны, планы)

1. Положи картинку в `assets/designs/`.
2. Добавь в `DESIGN_PHOTOS` (для send_design) или используй `send_photo(chat_id, путь, подпись)`.
3. Отправка идёт multipart-загрузкой локального файла, лимит фото 10 МБ.

## Применить изменения и проверить

После правки `server.py` ВСЕГДА перезапусти и проверь — иначе живой бот работает
на старом коде (это типичная ловушка):

```bash
cd ~/Desktop/krutim-tut-bot
python3 -m py_compile server.py bot.py   # проверка синтаксиса
./manage.sh restart                      # перезапуск + ожидание webhook (до 3 мин из-за DNS)
./manage.sh status                       # процессы, сервер, webhook
./manage.sh test "новое ключевое слово"  # отправить боту тестовое сообщение
./manage.sh logs                         # логи супервизора и принятых сообщений
```

Быстрая проверка ответа без перезапуска (импорт не запускает Flask):
```bash
python3 -c "import server; print(server.instant_answer('твой запрос'))"
```

## Команды бота для отдела запуска

- Партнёр пишет: **локация / найм / открытие** → чек-лист с галочками.
- Партнёр пишет: **дизайн** → 3 фото форматов точек. **планы / чертежи** → планы мебели и розеток.
- **`/admin крутим2026`** → открыть доступ к отчёту. **`/svodka`** → сводка по всем партнёрам.
- Партнёр шлёт фото/видео → сохраняется в его карточку.

## Ловушки (проверено на практике)

- **Один поллер.** В bot.py стоит файловый замок (fcntl) — два экземпляра не должны
  поллить одновременно, иначе дубли ответов. Webhook-режим (server.py) и поллинг
  (bot.py) одновременно не запускай.
- **Webhook и DNS.** Новый адрес trycloudflare иногда не резолвится у Telegram пару
  минут (negative cache). Супервизор сам пересоздаёт туннель — после `restart` дай
  ему до 3 минут, проверяй `./manage.sh status`.
- **Секреты.** Не коммить реальные ключи в код — GitHub push protection заблокирует.
  Токен/ключи только в `.env` (он в .gitignore). В коде бери из переменных окружения.
- **partners.json** — рабочие данные, в .gitignore, не трогать руками без нужды
  (живой сервер держит их в памяти и перезапишет).
- Бот живёт, пока Мак включён и не спит. Для 24/7 без компа нужен постоянный сервер.

## Факты франшизы (для достоверных ответов)

- Сеть ~47 точек, цель 300 к 2029. Роялти 5% от выручки.
- Старт: ~60 чеков/день, выручка 400-600 тыс/мес. Через 3 мес ~1,2 млн.
  В пик 1,7-1,9 млн на точку. Сезон: январь ~890к, август пик ~1,9 млн, декабрь ~1,2.
- Персонал на старте: один повар-кассир в одном лице + сам собственник на точке.
  Двух-трёх не нанимают, пока выручка смены не дойдёт до 25-35 тыс, потом два повара 2/2.
- Зарплата: 200 руб/час (~2400/смена) + бонус от выручки 5-10% + премия за средний чек >600.
- Помещение: 15-25 м², потолки от 2,8 м, электричество 15 кВт, вода, канализация, вытяжка.
- 3 формата точек: компактная навынос; большая с зоной ORGANIC, кофе и мороженым;
  с посадкой «Крутим Жарим» (диваны, барная стойка).
- Материалы: штукатурка «эффект бетона», панно «Скала», рейки 40×16 мм, профнастил С8
  графит RAL 7024, керамогранит 60×120 (Italon/Delacora), LED-панели Eleganz 50Вт 6000K.
- Касса: онлайн с фискальным накопителем, удобен Эвотор. ИП, ОКВЭД 56.10.
- Последовательность запуска: локация → дизайн под помещение → оборудование → ремонт.
