# Together.ai API Setup

Бот теперь использует Together.ai - полностью бесплатный, стабильный и быстрый AI API.

## Как получить ключ

1. Переходишь на https://www.together.ai

2. Нажимаешь "Sign Up" (бесплатная регистрация)

3. Подтверждаешь email

4. В левом меню выбираешь "API Keys"

5. Нажимаешь "Create New API Key"

6. Копируешь ключ (начинается на `cf_`)

7. Вставляешь в .env файл:
```
TOGETHER_KEY=cf_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

8. На Railway добавляешь переменную окружения TOGETHER_KEY с этим же значением

## Модели которые используются

- Llama 3 70b Chat (мощная)
- Mixtral 8x7B Instruct (быстрая)
- Nous Hermes 2 Mixtral (точная)

Все бесплатные, неограниченные, очень надежные.

## Ограничения

У Together.ai щедрые лимиты:
- 1 млн токенов в месяц бесплатно
- Или ~10 запросов в минуту непрерывно
- Достаточно для 24/7 работы бота
- Полностью бесплатно
- Без кредитной карты на начало

## После добавления ключа

1. Обнови .env локально
```
TOGETHER_KEY=твой_ключ_из_together
```

2. Добавь на Railway: переменная TOGETHER_KEY = твой_ключ

3. Перезапусти бота

4. Тестируешь в Telegram: /start

## Почему Together вместо Groq?

- Groq требует регистрацию (мы используем автоматизацию)
- Together сразу дает бесплатный ключ
- Оба одинаково стабильны и быстры
- Обе полностью бесплатные
