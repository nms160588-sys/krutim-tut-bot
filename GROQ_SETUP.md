# Groq API Setup

Бот теперь использует Groq - полностью бесплатный и стабильный AI API.

## Как получить Groq ключ

1. Перейди на https://console.groq.com

2. Нажми "Sign Up" (или "Sign In" если есть аккаунт)

3. Подтверди email

4. В левом меню выбери "API Keys"

5. Нажми "Create API Key"

6. Скопируй ключ

7. Вставь его в .env файл:
```
GROQ_KEY=gsk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

8. На Railway добавь переменную окружения GROQ_KEY с этим же значением

## Modели которые используются

- Mixtral 8x7b (мощная)
- Llama 3.1 70b (быстрая)
- Gemma 7b (легкая)

Все бесплатные, неограниченные, и очень стабильные.

## Ограничения

У Groq очень щедрые лимиты:
- ~100 запросов в минуту (более чем достаточно)
- Полностью бесплатно
- Без кредитной карты

## После добавления ключа

1. Обнови .env локально
2. Пересохрани на Railway
3. Перезапусти бота
4. Готово!

Бот больше не будет падать от перегрузки OpenRouter.
